# Seu_Banco
Sistema bancário simples desenvolvido em Python para praticar programação orientada a objetos, herança, métodos, entrada de dados e estruturas de repetição.
O Seu-Banco permite que o usuário consulte informações de uma conta bancária e realize operações básicas por meio de um menu interativo.

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de Python e melhorar minhas habilidades de programação.

-Funcionalidades

Consultar o nome do titular da conta.

Consultar o saldo disponível.

Depositar dinheiro.

Consultar a taxa de juros.

Aplicar juros ao saldo da conta.

Navegar por um menu interativo no terminal.

-Conceitos praticados

Classes e objetos.

Construtores (__init__).

Herança entre classes.

Uso de super().

Atributos e métodos.

Estruturas de repetição (while).

Condicionais (if, elif e else).

Entrada de dados com input().

Formatação de valores monetários.

Tratamento de erros com try e except, caso implementado.

Objetivo de aprendizagem

Este projeto faz parte dos meus estudos de Python e representa uma etapa do meu aprendizado em programação orientada a objetos.

Pretendo continuar aprimorando o sistema, adicionando novas funcionalidades e melhorando a organização do código.
